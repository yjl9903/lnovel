# 分卷 EPUB 下载

## 背景和目标

复用相邻 epubook 仓库的生成思路，在小说详情页每卷操作组第二位加入「下载 EPUB」。浏览器获取现有 API 数据并生成文件，不新增服务端下载接口或数据库结构。

## 已确认决策

- Web 固定使用 `@epubook/core`、`@epubook/bundler`、`@epubook/xml` 的 `0.0.12-beta.4`，按点击动态加载。
- 仅导出 `done === true` 且目录非空的卷；未就绪提示稍后重试，不轮询、不传 `force`。
- 正文、封面或插图失败均中止，不导出残缺文件；没有封面地址允许导出。
- 页面同时运行一个任务，使用 Sonner toast 显示分阶段进度及结果，在 toast 中提供取消和失败重试；分卷行不展示状态文案，离开页面取消并清理通知。
- 图片同源代理、去重并嵌入；AVIF 转 PNG。HTML 解析后清理，再序列化为 XHTML。
- EPUB 书名优先直接使用分卷标题，仅标题为空时拼接小说名与卷号；文件名复用该书名。简介按卷简介、小说简介、EPUB 书名回退，避免上游空 `dc:description` 格式问题。
- 不提供后台下载、持久化缓存、断点续传；不改 README。

## 实施与验收

实现浏览器导出模块、图片处理和页面任务状态，维护 Web 架构及测试说明。使用本地 JSON/图片 fixture 验证 ZIP 内部引用、目录、正文、元数据和失败取消行为；执行生产构建、类型检查和全量测试；用 EPUBCheck、浏览器和阅读器验收生成文件。

状态：实现完成。

## 实际验证结果

- Node.js 24.15.0、pnpm 12.3.4。
- `pnpm build`、`pnpm typecheck`、`pnpm test:ci` 全部通过；Web 共 135 个测试通过，其中新增导出与任务生命周期测试 36 个。
- Chrome 实际验收通过：点击前不加载 EPUB 模块或卷/章节数据；按钮顺序正确；桌面与 375px 布局无水平溢出；完整下载、未就绪提示、插图失败中止、取消与重试正常；无页面脚本错误。
- Chrome 下载的本地 fixture EPUB 经 EPUBCheck 5.3.0 校验，0 错误、0 警告。Calibre 8.9 能读取元数据、加载封面和正文；目录跳转、章节顺序、中文转义、换行与 ruby 注音已在阅读器检查。
- 完整生成模块为独立动态 chunk，当前构建约 79.76 KB gzip，不计复用的简介解析 chunk。早期 16 KB 探测只包含最小底层打包路径，不能用作完整功能体积。
- 浏览器和阅读器仅使用本地 JSON 与 PNG fixture，没有验证在线抓取、真实书籍插图、Safari/Firefox 或真实移动设备；AVIF 转换通过受控解码/canvas 测试，未使用真实 AVIF 做浏览器验收。
- 验收截图、下载文件与浏览器 profile 均位于临时目录，未加入仓库。

## 状态提示调整

按用户反馈，将分卷行内进度与结果移至 Sonner toast。复用任务通知 ID 更新进度，保留卷名、取消和错误重试，结束后移除取消操作并设置自动消失时间；根布局统一挂载 Toaster。

调整后重新通过 `pnpm build`、`pnpm typecheck`、`pnpm test:ci`（Web 135 个测试）。生产构建配合本地 API fixture，在内置浏览器验证进度、取消、成功、未就绪重试和离页清理；375px 视口下通知与按钮无水平溢出，控制台无错误。该视口验证不代替真实手机设备验收。

后续按反馈将通知图标对齐标题首行，取消/重试按钮移至文案下方单独一行；成功提示延长至 8 秒，取消提示仍为 4 秒。Web 构建、类型检查及任务生命周期的 4 个测试通过；本地长卷名 fixture 在桌面与 375px 视口确认图标中心与标题首行中心对齐，按钮位于文案下方且无水平溢出。

## 命名修正

原实现无条件拼接小说名和分卷标题，造成完整分卷标题重复书名，或混合不同译名。改为优先使用原站分卷标题，空标题才回退到小说名与卷号，并统一应用于文件名、`dc:title`、封面替代文本及简介最终回退值。新增 6 组解压回归用例；导出与任务测试共 42 个通过，Web 类型检查通过。
